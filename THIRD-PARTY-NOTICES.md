# Avisos de software de terceros

ARCA usa los paquetes de código abierto que se listan aquí, cada uno con su licencia. Este fichero lo genera
`build/CheckLicenses.cs` y los scripts de verificación fallan si está desactualizado. Para regenerarlo:
`dotnet run build/CheckLicenses.cs -- --write-notices`.

Solo se aceptan licencias compatibles con la GPL-3.0 (MIT, Apache 2.0, BSD, ISC). Las excepciones revisadas a mano
están en `build/licenses-reviewed.json`, con su motivo.
