# Arca
ARCA — Administració de Recursos, Claus i Armariets. Aplicació d’escriptori per gestionar l’assignació d’armariets, els pagaments, el lliurament i retorn de claus, les incidències i el manteniment en centres educatius.

Programari lliure i gratuït. Llicència: GNU GPL v3.0 (vegeu `LICENSE`). El nom «ARCA» i el seu logotip són marca del titular (vegeu `TRADEMARK.md`).
